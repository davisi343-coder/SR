Help & How-To Guide · Single Action Score Sheets

★ Use CSV or XLSX file from Practiscore 2 - click on Import/Export > Export Registration

1. CSV & XLSX File Import & Column Allocations

  • Supported Formats: Upload either .xlsx or .csv PractiScore registration exports.
  • Selective Columns: Only uses columns that have headers of Alias, Squad, and Division; all other columns are safely ignored.
  • Squad Allocation: The Squad column allocates competitors into their respective posses (e.g. 1 becomes Posse 1).

2. Posse Sets & 25 Shooters Capacity

  • Max Capacity: Supports up to 25 shooters per posse on each sheet.
  • Default Setting: Set to "All Posses" so each posse receives a complete set of sheets.
  • Print Posse Lists: Choose "Print posse lists" in the Posse Set dropdown to generate clean rosters (one posse per page, alias with division underneath, centered, no dividing line).
  • Alphabetical Order: Competitor aliases within each posse are automatically sorted alphabetically (A to Z).
  • Full Sets: Selecting "All Posses" prints a complete sequential set of stage sheets (Stages 1 to N) for every posse.

3. Stage Dropdown (1 to 12)

  • Use the Stages (1-12) dropdown to choose anywhere between 1 and 12 stages for your match.

4. Download PDF & Print Options

  • Click "Download PDF" to generate and save a `.pdf` file directly to your downloads.
  • Click "Print Sheets" to print directly or choose "Save as PDF" in your browser print window.
  • Ensure Paper Size is set A4, Orientation is Portrait, and Margins are set to None or Minimum.
  • In blank mode, the header prints simply as "Posse" (without a number) for manual squad numbering.
